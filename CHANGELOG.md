## [v0.1.0] - 2026-05-25

### Highlights

- Initial release of web-tools monorepo with browser-based developer tools built as Lit Web Components
- Three standalone tools: Markdown Editor, JWT Editor, and Coordinate Picker
- Reusable site-nav component package for navigation, headers, badges, and theme toggle

### Added

- Monorepo structure with pnpm workspaces ([`413bd09`](https://github.com/grokify/web-tools/commit/413bd09))
- Markdown Editor: Live preview with GitHub Flavored Markdown, syntax highlighting, and export options ([`50d8cda`](https://github.com/grokify/web-tools/commit/50d8cda))
- JWT Editor: Decode, edit, and re-sign JWTs with support for HS256/HS384/HS512 algorithms ([`efb0ed1`](https://github.com/grokify/web-tools/commit/efb0ed1))
- Coordinate Picker: Interactive map tool for selecting and managing geographic coordinates ([`404661a`](https://github.com/grokify/web-tools/commit/404661a))
- site-nav package with wt-navbar, wt-header, wt-badge, wt-theme-toggle, wt-mega-menu, wt-mobile-menu components ([`4d37c9d`](https://github.com/grokify/web-tools/commit/4d37c9d))
